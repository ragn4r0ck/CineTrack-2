# CinéTrack v2

CinéTrack v2 est une application web de catalogue de films et de séries.
Elle est écrite en HTML, Tailwind CSS et JavaScript natif.

## Objectif

Permettre aux visiteurs de parcourir un catalogue et aux administrateurs de gérer
les films et les séries depuis une page dédiée.

## Structure du projet

```text
CineTrackv2/
├── index.html         Page catalogue
├── admin.html         Page d'administration
├── js/                Code JavaScript
└── README.md          Documentation du projet
```

## Lancer le projet

Le projet utilise les modules JavaScript natifs. Il doit être servi par un
petit serveur HTTP local, par exemple avec **Live Server** dans VS Code.
